Rules of thumb
Serif

Names, descriptions, titles, anything narrative. Use italic for display moments (page titles, section headers). Regular weight by default — avoid bold.

Mono

All numbers (currency, dates, percentages). Labels and small captions in uppercase with wide tracking. Weight 500 for emphasis, 400 for decimals.

Currency symbol

"Rs" is always set in italic serif, sized smaller than the numeric value it sits next to. It is part of the narrative, not the number.

01.5

Motion

Motion is functional, not decorative. Use short durations (under 200ms) for most hover and tap responses. Easing stays default (ease) unless animating sheets or modals.

color
.15s — hover color shifts on links, icons, secondary buttons
background
.12s — row hover backgrounds, key press feedback
border-color
.15s — card and input focus / hover
transform: scale
.08s — tap-down feedback on calc keys, FAB
width (progress)
.3s — budget progress bar fill changes
opacity (blink)
1s — cursor blink (50% on / 50% off, infinite)
