02 — Components

Components

The reusable building blocks of the FlowFin interface — buttons, cards, form rows, badges, sheets. Every component is live (not screenshotted).

02.1

Buttons

One primary action per screen. Mono labels in uppercase with wide tracking — this is one of the few places body type goes into mono.
