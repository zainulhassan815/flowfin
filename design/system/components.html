02.22

Empty states

Four categories, four treatments. Match the category to the data condition — don't reuse a takeover where a hint is enough, and don't downgrade a takeover into a hint. The full per-screen inventory lives in docs/empty-states.md.

FFull empty
Screen takeover. Editorial moment with eyebrow / italic title / body / CTA. Hero muted or hidden, FAB hidden if its action depends on missing data. Used when nothing can be done on the screen until the user adds the missing thing.
SSection empty
Inline dashed-border hint inside a populated screen. Short, quiet, optional small link. Never takes over. Used when one section has no data but the rest of the screen carries the user's existing state.
QFilter / search
Filter or search scaffolding stays visible. Inline notice in the body echoes the query terms in a serif chip + mono callout, with action links to clear the filter or adjust the search.
NNot-enough-yet
Calm, informational — no CTA. The user can't act, they need time. Often paired with a small progress pill (Day N / 28) or a faded preview of what the populated state will look like.
